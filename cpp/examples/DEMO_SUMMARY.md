## 🚀 使用方法

### 基本用法
```bash
# 构建程序
cd build
ninja gis_storage_demo

# 运行演示
cd examples
./gis_storage_demo <输入Shapefile> <输出目录>

# 示例
./gis_storage_demo ../../data/test.shp ./demo_output
```

### 使用脚本
```bash
# 使用测试数据
./run_demo.sh --test

# 使用自定义数据
./run_demo.sh --clean ../data/test.shp ./output

# 详细模式
./run_demo.sh --verbose ../data/test.shp ./output
```
