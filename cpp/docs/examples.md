# GIS存储系统演示程序

这个演示程序展示了如何使用GIS存储系统一次性完成Shapefile/FileGDB转换、S2索引构建和元数据生成。

## 功能特性

- **完整的处理流程**：从Shapefile/FileGDB到优化存储格式的完整转换
- **S2空间索引**：自动构建高性能的S2空间索引
- **元数据管理**：自动生成和管理完整的元数据信息
- **数据访问演示**：展示如何读取转换后的数据
- **空间查询演示**：展示S2空间索引的查询功能
- **属性查询演示**：展示高效的属性查询功能
- **云南瓦片查询**：演示实际应用场景的空间查询
- **逆向转换**：展示如何将自定义格式转换回标准GIS格式
- **性能统计**：详细的处理时间和文件大小统计
- **错误处理**：完善的错误检查和异常处理

## 构建方法

### 1. 使用CMake构建

```bash
# 在项目根目录下
mkdir build
cd build
cmake ..
make gis_storage_demo
```

### 2. 使用Ninja构建

```bash
# 在项目根目录下
mkdir build
cd build
cmake -G Ninja ..
ninja gis_storage_demo
```

## 使用方法

### 基本用法

```bash
# 完整处理流程
./gis_storage_demo <输入GIS文件路径(.shp/.gdb)> <输出目录>

# 仅瓦片查询演示
./gis_storage_demo <现有数据目录> [数据集名称]
```

### 示例

```bash
# 使用Shapefile进行完整处理
./gis_storage_demo ../data/test.shp ./output

# 使用FileGDB进行完整处理
./gis_storage_demo ../data/test.gdb ./output

# 仅进行瓦片查询演示（自动检测数据集）
./gis_storage_demo ./output

# 仅进行瓦片查询演示（指定数据集名称）
./gis_storage_demo ./output DLTB_2021CG
```

## 处理流程

### 完整处理流程

演示程序按以下步骤执行：

1. **验证输入文件** - 检查GIS文件是否存在和有效
2. **转换GIS格式** - 将Shapefile/FileGDB转换为优化的存储格式
3. **初始化存储系统** - 设置存储系统并加载转换后的数据
4. **构建S2空间索引** - 创建高性能的空间索引
5. **生成和保存元数据** - 创建完整的元数据文件
6. **验证处理结果** - 检查所有生成的文件
7. **数据访问演示** - 展示如何读取转换后的数据
8. **云南瓦片查询演示** - 展示实际应用场景的空间查询
9. **逆向转换演示** - 展示如何转换回标准GIS格式
10. **显示统计信息** - 输出详细的处理统计

### 瓦片查询演示流程

仅瓦片查询模式按以下步骤执行：

1. **轻量级加载** - 仅加载S2索引和元数据
2. **属性查询演示** - 展示高效的属性查询功能
3. **云南瓦片查询演示** - 展示实际应用场景的空间查询
4. **显示统计信息** - 输出数据统计信息

## 输出文件

处理完成后，会在输出目录中生成以下文件：

- `{dataset_name}.geom` - 几何数据文件（二进制格式）
- `{dataset_name}.attr` - 属性数据文件（二进制格式）
- `{dataset_name}.pool` - 字符串池文件（优化字符串存储）
- `{dataset_name}.idx` - 索引数据文件（JSON格式）
- `{dataset_name}_meta.json` - 元数据文件（JSON格式）
- `{dataset_name}.s2idx` - S2空间索引文件（二进制格式）

## 错误处理

程序包含完善的错误处理机制：

- **输入验证**：检查文件存在性和有效性
- **转换错误**：捕获并报告转换过程中的错误
- **索引构建错误**：处理S2索引构建失败的情况
- **文件访问错误**：处理文件读写权限问题
- **内存不足**：处理大数据集的内存限制

## 性能优化

- **增量写入**：支持大数据集的增量处理
- **内存优化**：使用高效的数据结构
- **并行处理**：S2索引构建支持多线程
- **压缩存储**：自动压缩字符串数据

## 依赖项

- **GDAL**：用于读取Shapefile
- **S2库**：用于空间索引
- **nlohmann/json**：用于JSON处理
- **Boost.Geometry**：用于几何计算
- **TBB**：用于并行处理

## 故障排除

### 常见问题

1. **文件不存在错误**
   - 检查输入文件路径是否正确
   - 确保文件权限允许读取

2. **内存不足错误**
   - 对于大数据集，考虑分批处理
   - 增加系统内存或使用交换空间

3. **权限错误**
   - 确保输出目录有写入权限
   - 检查磁盘空间是否充足

4. **GDAL错误**
   - 确保GDAL正确安装
   - 检查Shapefile格式是否有效

### 调试模式

可以通过设置环境变量启用详细日志：

```bash
export GDAL_DEBUG=ON
./gis_storage_demo input.shp output/
```
