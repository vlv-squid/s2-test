# 基准测试

## ⚡ 性能测试

### 空间索引基准测试
- **程序**: `spatial_index_benchmark`
- **功能**: 测试S2空间索引的构建和查询性能
- **数据**: 支持Shapefile和FileGDB格式
- **指标**: 索引构建时间、查询响应时间、内存使用

### 文件I/O性能测试
- **程序**: `file_io_performance_test`
- **功能**: 测试文件读写性能
- **指标**: 读写速度、内存使用、并发性能

### GDAL FileGDB性能测试
- **程序**: `gdal_filegdb_performance_test`
- **功能**: 测试GDAL FileGDB格式的读写性能
- **指标**: 读取速度、内存使用、格式兼容性

### 自定义格式性能测试
- **程序**: `custom_format_performance_test`
- **功能**: 测试自定义存储格式的性能
- **指标**: 转换速度、存储效率、查询性能

## 🚀 运行基准测试

### 使用脚本
```bash
# 运行基准测试脚本
./tools/benchmark/run_cpp_benchmark.sh
```

### 直接运行
```bash
cd build/benchmarks
./spatial_index_benchmark
```

### 运行性能测试
```bash
cd build/tests
./file_io_performance_test
./gdal_filegdb_performance_test
./custom_format_performance_test
```

## 📊 性能指标

### S2索引性能
- **构建时间**: 索引构建耗时
- **查询时间**: 空间查询响应时间
- **内存使用**: 索引内存占用
- **文件大小**: 索引文件大小

### 存储性能
- **转换速度**: Shapefile/FileGDB转换速度
- **读写速度**: 数据文件读写速度
- **压缩率**: 数据压缩效果
- **并行性能**: 多线程处理性能
- **内存效率**: 内存使用优化效果

## 📈 性能优化

### 索引优化
- 调整S2层级设置（分辨率15-20）
- 优化批处理大小（1000-50000要素/批）
- 使用多线程构建（TBB并行处理）
- 智能索引完整性验证

### 存储优化
- 优化数据序列化（二进制格式）
- 使用内存映射（大文件处理）
- 实现数据压缩（字符串池优化）
- 并行属性查询（TBB多线程）
- 高效的空间属性复合查询

## 📋 测试数据

### 测试数据集
- 小数据集：< 10K 要素
- 中数据集：10K - 100K 要素
- 大数据集：> 100K 要素

### 测试场景
- 点数据索引
- 线数据索引
- 面数据索引
- 混合几何类型
- 大规模数据集（>100K要素）
- 多格式转换（Shapefile ↔ FileGDB）
- 空间查询性能
- 属性查询性能
- 复合查询性能
