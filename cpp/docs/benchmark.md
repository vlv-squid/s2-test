# 基准测试

## ⚡ 性能测试

### 空间索引基准测试
- **程序**: `spatial_index_benchmark`
- **功能**: 测试S2空间索引的构建和查询性能
- **数据**: 支持Shapefile格式

### 文件I/O性能测试
- **程序**: `file_io_performance_test`
- **功能**: 测试文件读写性能
- **指标**: 读写速度、内存使用

## 🚀 运行基准测试

### 使用脚本
```bash
# 运行基准测试脚本
./tools/benchmark/run_cpp_benchmark.sh
```

### 直接运行
```bash
cd build/benchmarks
./spatial_index_benchmark
```

### 运行性能测试
```bash
cd build/tests
./file_io_performance_test
```

## 📊 性能指标

### S2索引性能
- **构建时间**: 索引构建耗时
- **查询时间**: 空间查询响应时间
- **内存使用**: 索引内存占用
- **文件大小**: 索引文件大小

### 存储性能
- **转换速度**: Shapefile转换速度
- **读写速度**: 数据文件读写速度
- **压缩率**: 数据压缩效果

## 📈 性能优化

### 索引优化
- 调整S2层级设置
- 优化批处理大小
- 使用多线程构建

### 存储优化
- 优化数据序列化
- 使用内存映射
- 实现数据压缩

## 📋 测试数据

### 测试数据集
- 小数据集：< 10K 要素
- 中数据集：10K - 100K 要素
- 大数据集：> 100K 要素

### 测试场景
- 点数据索引
- 线数据索引
- 面数据索引
- 混合几何类型
