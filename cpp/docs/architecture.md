# 系统架构

## 🏗️ 整体架构

GIS存储系统采用模块化设计，主要包含以下核心模块：

### 1. GIS索引模块 (gisindex)
- **S2空间索引** - 基于Google S2几何库的高性能空间索引
- **序列化支持** - 高效的二进制序列化/反序列化
- **多层级索引** - 支持不同精度的空间索引
- **智能索引管理** - 自动检测和构建索引

### 2. GIS存储模块 (gisstorage)
- **几何数据存储** - 高效的几何数据存储和管理
- **属性数据管理** - 属性数据的存储和查询
- **字符串池优化** - 字符串数据的去重和优化
- **OGR格式转换** - 支持Shapefile、FileGDB等多种格式转换
- **逆向转换** - 支持将自定义格式转换回标准GIS格式

### 3. 存储系统 (GisStorageSystem)
- **统一接口** - 提供统一的存储和查询接口
- **元数据管理** - 数据集元数据的管理
- **文件扩展名管理** - 标准化文件扩展名定义
- **并行查询** - 支持多线程属性查询
- **空间属性复合查询** - 结合空间和属性的高效查询

## 📁 模块依赖关系

```
GisStorageSystem
├── GeometryStorage
├── AttributeStorage
├── StringPool
├── OGRFormatConverter
│   ├── 支持Shapefile转换
│   ├── 支持FileGDB转换
│   └── 支持逆向转换
└── S2SpatialIndex
    ├── SerializeS2
    ├── 多线程构建支持
    └── 智能索引管理
```

## 🔧 核心组件

### S2空间索引
- 支持多层级空间索引（分辨率可配置）
- 高效的球面几何计算
- 二进制文件格式存储
- 多线程构建支持
- 智能索引完整性验证

### 数据存储
- 几何数据：`.geom` 文件（二进制格式）
- 属性数据：`.attr` 文件（二进制格式）
- 字符串池：`.pool` 文件（字符串去重优化）
- 索引数据：`.idx` 文件（JSON格式）
- 元数据：`_meta.json` 文件（JSON格式）
- S2索引：`.s2idx` 文件（二进制格式）

### 文件格式特点
- 二进制格式，高效读写
- 支持大数据集处理
- 无外部数据库依赖
- 完整的元数据管理
- 支持数据完整性验证

### 查询功能
- 空间查询：基于S2索引的高效空间查询
- 属性查询：支持精确匹配、模式匹配和值查询
- 并行查询：使用TBB实现多线程属性查询
- 复合查询：结合空间和属性的高效查询
