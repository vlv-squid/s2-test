# GIS存储格式性能测试工具

本工具用于对比自定义GIS存储格式与Python OGR库在文件读取解析和空间查询方面的性能差异。

## 功能特性

### 1. 基础性能测试 (`performance_comparison.py`)
- **顺序读取测试**: 对比两种格式的顺序读取性能
- **随机读取测试**: 对比两种格式的随机访问性能  
- **空间查询测试**: 对比两种格式的空间查询性能
- **多种测试规模**: 支持100、1000、10000等不同规模的测试

### 2. 详细性能分析 (`detailed_performance_analysis.py`)
- **多次重复测试**: 每个测试重复5次，计算统计信息
- **统计分析**: 计算均值、中位数、标准差等统计指标
- **性能图表**: 自动生成性能对比图表
- **结果保存**: 将测试结果保存为JSON格式

### 3. 便捷运行脚本 (`run_performance_test.py`)
- **多种测试模式**: 支持基础、详细、快速三种测试模式
- **命令行参数**: 支持指定数据文件、测试类型、输出目录
- **错误处理**: 完善的错误处理和提示信息

## 安装依赖

```bash
pip install matplotlib numpy statistics
```

## 使用方法

### 1. 快速开始

```bash
# 运行基础性能测试
python run_performance_test.py

# 运行详细性能测试
python run_performance_test.py --test-type detailed

# 运行快速性能测试
python run_performance_test.py --test-type quick
```

### 2. 自定义参数

```bash
# 指定数据文件
python run_performance_test.py --shapefile ./data/my_data.shp

# 指定输出目录
python run_performance_test.py --output-dir ./my_results

# 组合使用
python run_performance_test.py -s ./data/my_data.shp -t detailed -o ./my_results
```

### 3. 直接运行模块

```bash
# 运行基础对比测试
python performance_comparison.py

# 运行详细分析
python detailed_performance_analysis.py
```

## 测试内容

### 1. 文件读取解析性能

#### 顺序读取测试
- **测试内容**: 按顺序读取几何数据和属性数据
- **测试规模**: 100, 500, 1000, 5000, 10000个要素
- **性能指标**: 读取速率 (要素/秒)

#### 随机读取测试
- **测试内容**: 随机访问指定要素的几何数据和属性数据
- **测试规模**: 100, 500, 1000, 5000, 10000个要素
- **性能指标**: 读取速率 (要素/秒)

## 性能分析

### 1. 读取性能分析

#### 顺序读取
- **OGR优势**: 标准格式，兼容性好
- **自定义格式优势**: 二进制存储，差分编码压缩
- **适用场景**: 批量数据处理

#### 随机读取
- **OGR劣势**: 需要顺序扫描或建立索引
- **自定义格式优势**: 偏移索引，直接定位
- **适用场景**: 随机访问场景

### 2. 空间查询分析

#### 查询策略
- **OGR**: 基于空间索引的过滤
- **自定义格式**: S2空间索引 + R树优化

#### 性能优势
- **索引效率**: S2索引提供更精确的空间划分
- **查询速度**: 混合索引策略减少候选集大小
- **内存使用**: 优化的数据结构减少内存占用

## 测试建议

### 1. 数据准备
- 确保Shapefile文件完整（.shp, .shx, .dbf等）
- 数据量建议在1000-100000个要素之间
- 包含多种几何类型（点、线、面）

### 2. 测试环境
- 使用SSD硬盘以获得最佳I/O性能
- 关闭其他占用资源的程序
- 多次运行取平均值

### 3. 结果解读
- 关注性能提升的稳定性
- 考虑不同数据规模下的表现
- 结合具体应用场景选择合适格式

## 故障排除

### 1. 常见问题

#### 找不到数据文件
```
错误: 找不到Shapefile文件 ./data/test.shp
```
**解决方案**: 检查文件路径，确保文件存在

#### 导入模块失败
```
ModuleNotFoundError: No module named 'osgeo'
```
**解决方案**: 安装GDAL/OGR库
```bash
pip install GDAL
```

#### 内存不足
```
MemoryError: Unable to allocate array
```
**解决方案**: 减少测试规模或增加系统内存

### 2. 性能优化建议

#### 自定义格式优化
- 调整S2索引分辨率
- 优化差分编码参数
- 使用内存映射文件

#### 测试参数调整
- 根据数据特点调整测试规模
- 选择合适的查询范围
- 增加测试重复次数提高统计可靠性
